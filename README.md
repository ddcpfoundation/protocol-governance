# DDCP protocol governance

This repository holds the documents by which DDCP Foundation Inc stewards the Decentralized Digital Currency Protocol (DDCP): what the protocol commits to, the criteria against which a currency is examined, how that examination is made, how the protocol may change, and how the DDCP name may be used.

It holds no code and governs no currency. A currency built using the protocol is governed by its own issuer and described in its own published specification.

## Documents

| Document | What it is |
|---|---|
| [MANIFESTO.md](MANIFESTO.md) | The DDCP Manifesto: the qualities of better money and the commitments the protocol makes. Every other document here answers to it. |
| [CRITERIA.md](CRITERIA.md) | The DDCP conformance criteria: fifteen criteria extracted from the Manifesto, against which a currency is examined. |
| [EVALUATION_METHODOLOGY.md](EVALUATION_METHODOLOGY.md) | How the Foundation examines a currency against the criteria and publishes the result. |
| [PROTOCOL_CHANGE_POLICY.md](PROTOCOL_CHANGE_POLICY.md) | How the protocol and its reference implementation may change, what can never be merged, and why no change ever applies to a currency already issued. |
| [TRADEMARK_USAGE_POLICY.md](TRADEMARK_USAGE_POLICY.md) | How the DDCP name may be used, including the provenance statements a currency may make. |

## Related repositories

- **The evaluation registry**, [ddcpfoundation/conformance-evaluations](https://github.com/ddcpfoundation/conformance-evaluations): the Foundation's published evaluations, made under the methodology in this repository.
- **The reference implementation** on Solana's Token-2022 program, in the [ddcpfoundation](https://github.com/ddcpfoundation) organization. Its own repository carries its specification and its Known Limits against DDCP.

## Proposals and contact

Proposals to change the protocol or the reference implementation are made as issues or pull requests in the reference implementation's repository, under [PROTOCOL_CHANGE_POLICY.md](PROTOCOL_CHANGE_POLICY.md). Security matters follow that repository's SECURITY file. Other matters: contact@ddcpfoundation.org.
